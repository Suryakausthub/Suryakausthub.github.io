Agent engineering

How I design and
build agents

An agent is a system, not a prompt. Most of the work is deciding what data it needs, how it retrieves that data, what must be computed exactly, and how its output is checked. Below are the six stages I follow, then the architecture of the agent they produce.

My engineering process

  1. Understand

    The decision, its inputs and the cost of a wrong answer

  2. Architect

    Data sources, components and the code-versus-model split

  3. Orchestrate

    Step order, tool calls, retries and call limits

  4. Implement

    Deterministic logic, prompts and integrations

  5. Validate

    Guardrails, scenario tests and output checks

  6. Iterate

    Fix what fails, then test on real data

Agent architectureHow data flows through a running agent. Code produces the facts; the model works on top of them.
